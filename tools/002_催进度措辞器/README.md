# 工具 #002｜催进度措辞器

直接双击 `index.html`，在浏览器中使用。

- 不联网、不上传、不保存输入内容。
- 生成的是 3 种可编辑的沟通草稿，不是“AI 自动催人”。
- 拍摄时用虚构的脱敏项目名称，避免在视频中泄露公司、人名、客户或未公开的业务信息。

## 短视频录屏顺序

1. 先展示三种成品语气（0–2 秒）。
2. 再输入“要什么 / 什么时候要 / 为什么需要”（2–8 秒）。
3. 点击生成，三种话术依次出现（8–15 秒）。
4. 停在“如果时间有困难，提前说，一起调整”这句（15–18 秒）。
5. 定格“工具 #002｜你最怕发哪种工作消息？”（18–20 秒）。
