C盘空间急救向导

C盘红得发紫，先别装"清理大师"。勾选下面你电脑里有的东西，我给你生成一张按"能省多少"排序的安全清理清单——每一步都先看后删，删不删你说了算。

隐私边界（先读这句）：这是个本地网页，碰不到你的硬盘——这是好事。它不扫描、不联网、不自动删除任何文件；它只把"该清理哪里"变成一张你能看懂的清单，命令复制到你自己的终端里跑。

第一步：勾选你电脑里有的

不确定的就不勾，清单里不会出现你不认识的东西。

🚫 别删清单（重要程度不亚于上面）

  • WinSxS 文件夹不要手动删——那是系统组件库，手删必坏。想瘦身只用系统命令：
    Dism.exe /Online /Cleanup-Image /StartComponentCleanup
  • pagefile.sys / swapfile.sys 不要直接删——通过"系统属性→高级→虚拟内存"调整。
  • AppData 整个文件夹不要删——软件配置全在里面，删完一堆软件失忆。
  • "C盘搬家 / 一键深度清理"类软件本身慎装——很多是弹窗广告和流氓捆绑的源头，这向导存在的意义就是让你不用装它们。
