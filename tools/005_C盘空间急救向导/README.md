## 诚实边界（这个工具的立身之本）

- **不装成扫描器**：浏览器碰不到硬盘，这是物理事实也是隐私卖点，不做假的"扫描动画"
- 不联网、不自动删除任何文件；所有删除命令默认 `-WhatIf` 只看不删
- 每项标注风险等级；附"别删清单"（WinSxS / pagefile / AppData / 流氓清理软件）
- 页脚如实写"用 AI 辅助开发"——吸取 #001 标题教训

## 为什么它能成（对 #001 的修正）

## 长度策略（2026-08-27 本人确认放宽）

- 长度是**待测变量**不是偏好：本条按约 45 秒长版发，完播率仲裁——还行 → 以后按内容定长度；拉胯 → #003 退回 25–35s，长内容转图文（图文 2:视频 1 配比承接）
- 长版生死线：**每 3–5 秒一个新信息点**，没有一秒喘气画面
- 钩子规则不随长度放宽：0–3 秒照旧，解放的是中段不是开场
- 幕后可嵌入 10 秒（一个具体问题→一次修改），完整幕后仍独立成篇
