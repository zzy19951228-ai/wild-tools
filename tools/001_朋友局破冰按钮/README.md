# 工具 #001｜朋友局破冰按钮

这是“野生 AI 工具匠”的最终首发 MVP。

直接双击 `index.html`，用浏览器打开。它只在本地运行：不联网、不上传、不保存任何输入内容。

## 工具机制

输入：人数、熟悉程度、想要的氛围。  
输出：一条可直接开始的、友好且能跳过的破冰题。

当前首发版本没有接入大模型。内容表面上不假装“AI 自动生成”，对外的准确表达是：

> “我是做大模型应用的，先把我觉得最容易尴尬的朋友局场景，做成了一个不会逼人的破冰按钮。”

后续收到评论区真实需求后，可再迭代为更细的场景题库或加上模型生成；首发先用可控、安全、能测试的 MVP 建立信任。

## 录屏顺序（20 秒）

1. 点击 `来个录屏示例`，先录下结果“无用颁奖”（作为 0–3 秒）。
2. 回到默认页，依次点“3–5 人 → 熟朋友 → 有点好笑”（3–8 秒）。
3. 点击“给我们一题”，让“无用颁奖”出现（8–12 秒）。
4. 点一次“换一题”，让第二题出现（12–15 秒）。
5. 定格在“任何人都可以跳过”的提示（15–18 秒），最后用编号页收尾（18–20 秒）。
