岗位个人权重打分器

没有"最好的岗位"，只有对你的权衡最划算的岗位。配一次你自己的 AI 模型（设置在右上角），以后只要把 JD 粘贴进来——AI 自动解析薪资、城市、硬性要求和红旗话术，按你的权重打好建议分，你确认或微调就行。

隐私边界：权重、岗位、你的 API Key 全部只存在你自己的浏览器里（localStorage），我们服务器不保存任何数据。AI 解析时，JD 文本和你的 Key 会经本站无状态代理转发到你自己配置的模型服务商，代理不记录、不存储。

第一步：你在乎什么？（决定 AI 给建议分的倾向）

第二步：粘贴 JD，AI 自动解析打分

从 BOSS/猎聘/任何地方复制岗位描述，整段粘进来 → 点解析 → 微调 → 入列。没配模型时也可以手动打分（下方）。

💡 建议：把候选的岗位都粘一遍——你粘的每个岗位都会进入下方"薪资总览"，你自己的市场行情会越用越准。

手动添加（不用 AI 也能用）

薪资总览（你的个人市场行情）

由你添加的岗位自动聚合（AI 解析的岗位自带薪资）；样本越多越准。

第三步：结果

加权总分排名 + 它为什么赢。回第一步换个档位试试——排名变了，就是这工具存在的理由。
