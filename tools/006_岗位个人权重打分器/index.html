岗位个人权重打分器

没有"最好的岗位"，只有对你的权衡最划算的岗位。配置一次你自己的 AI 模型，之后只需粘贴 JD——自动解析薪资、城市、硬性要求与红旗话术，按你的权重打好建议分，你确认或微调。

🔒 数据仅存本地浏览器🔑 API Key 不上传🧩 支持官方 / 中转站任意模型
AI 解析时，JD 文本与你的 Key 经本站无状态代理转发到你自己配置的模型服务商，代理不记录、不存储；权重、岗位、Key 全部只存在你的浏览器 localStorage。
STEP 01

你在乎什么？

点一个最像你的档位，再微调滑杆（0 = 不在乎，5 = 一票否决级重要）——权重决定 AI 给建议分的倾向。

STEP 02

粘贴 JD，AI 自动解析打分

从 BOSS / 猎聘 / 任何地方复制岗位描述，整段粘进来（Ctrl+Enter 触发）→ 微调 → 入列。

💡 把候选岗位都粘一遍——每个岗位都会进入"薪资总览"，你自己的市场行情越用越准。

MANUAL

手动添加

不想配模型也能用：手动打分 + 选填薪资城市（同样进入总览）。

MARKET

薪资总览

由你添加的岗位自动聚合（"杭州市" = "杭州"）；样本越多越准。

RESULT

结果

加权总分排名 + 它为什么赢。换个档位试试——排名变了，就是这工具存在的理由。
