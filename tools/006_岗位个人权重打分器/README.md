## 规格契约（tool-forge 第 2 步）

- **一个场景**：手上收藏了几个岗位，纠结哪个值得投——每个人的"值得"不一样
- **输入→输出**：设个人权重（5 维度滑杆 + 3 个预设档）→ 岗位逐维打分 1–5 → 加权排名 + 冠军拆解（赢在哪两个维度）
- **诚实边界**：分数用户自己打，工具只做结构化比较；本地 localStorage，不上传；"AI 辅助开发"，不假装自动评估岗位
- **演示时刻**：切换预设档（方向/钱/稳），第一名当场换人——"同一份列表，三个人选出三个答案"

## 三个预设档 = 内置的用户画像（化名，已脱敏）

方向优先（她）/ 钱优先（"春春"）/ 稳优先（"阿顾"）——档位名不用真名，内容红线执行。

## 001 号内测用户测试清单（给前同事，收集原话）

1. 五个维度够用吗？你最在乎的在里面吗？缺哪个？
2. 加一个岗位到打完分，超过 5 分钟了吗？（超了 = 太烦）
3. 算出来的排名，你服不服？不服的话——是权重没设对，还是工具没抓住你的纠结？
4. 有没有哪一刻你想"要是能 ___ 就好了"？（这句原话最值钱）
