# 工具 #004｜今晚吃什么决策器

双击 `index.html`，在浏览器中使用。它在本地从你列出的备选项中筛选，不联网、不调用地图或外卖数据。

## 20 秒视频结构

| 时间 | 画面 | 字幕 / 口播 |
|---:|---|---|
| 0–3 秒 | 先展示结果“就吃：牛肉饭” | “吃什么，不该靠转盘。” |
| 3–8 秒 | 填备选店、人均、距离 | “我先把预算和距离筛掉。” |
| 8–12 秒 | 填“不想吃辣” | “今天不想吃的，也排除。” |
| 12–16 秒 | 点击后亮结果，圆窗笑一下 | “剩下 2 家，再随机一次。” |
| 16–20 秒 | 定格工具 #004 | “工具 #004｜你最烦的是哪种选择？” |

注意：用虚构或公开店名录制，不展示订单、定位、聊天记录或真实住址。
